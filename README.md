# Weather Wear Advisor

Weather Wear Advisor - Android-приложение для подбора одежды по погоде. Пользователь может выбрать город или использовать текущее местоположение, посмотреть погодные условия, вести личный гардероб и получать рекомендации по подходящей одежде.

Приложение использует Firebase Authentication для входа и регистрации, OpenWeatherMap для получения погоды, Room для локального хранения данных и AndroidX Security Crypto для защищенного хранения пользовательских данных.
